# VC Doc Importer

Программа-браузер для Windows. VC.ru открывается **прямо внутри окна**
программы. Вы входите в свой аккаунт на самой странице, открываете новый пост —
и импортируете статью из `.docx` прямо в редактор VC. Программа **печатает**
статью как человек, поэтому жирный, курсив, заголовки, списки и цитаты не
сбрасываются, а изображения физически вставляются в редактор.

## Как это работает

Одно окно = встроенный браузер (движок Chromium через QtWebEngine). Редактор VC
сбрасывает форматирование при обычной вставке, но **на лету превращает markdown
в форматирование, когда вы печатаете**. Программа отправляет в поле статьи
настоящие нажатия клавиш, поэтому VC форматирует всё сам, как при ручном вводе:

| Что печатается | Что получается |
|----------------|----------------|
| `## Текст`     | Заголовок H2   |
| `### Текст`    | Заголовок H3   |
| `**жирный**`   | **жирный**     |
| `*курсив*`     | *курсив*       |
| `- пункт`      | список         |
| `1. пункт`     | нумерация      |
| `> цитата`     | цитата         |

Изображения кладутся в буфер обмена и вставляются (Ctrl+V) — VC загружает их
на сервер физически, в том же порядке, что в документе.

## Использование

1. Запустите программу — сразу открывается VC.ru внутри окна.
2. Войдите в свой аккаунт прямо на странице (логин сохраняется между запусками).
3. Создайте новый пост — откроется редактор VC в том же окне.
4. **Кликните в тело статьи** (где мигает курсор).
5. Нажмите **«Добавить документ»** на верхней панели или перетащите `.docx`
   в окно.
6. Смотрите, как статья заполняется. Проверьте и опубликуйте.

Кнопка **«Лог»** открывает окно с подробным логом и кнопкой «Копировать всё».
Если что-то пошло не так — скопируйте лог и пришлите.

## Рекомендации

- **Перед импортом кликните в тело статьи.** Программа печатает туда, где
  стоит курсор. Это единственное ручное действие.
- **Заголовок статьи** (верхнее большое поле) заполняйте вручную — это
  отдельное поле, не часть тела.
- **В Word применяйте настоящие стили** («Заголовок 1/2/3», «Список
  маркированный/нумерованный», «Цитата»), а не просто крупный жирный шрифт —
  иначе блок распознается как обычный абзац. Жирный/курсив внутри абзаца —
  как обычно.
- **Скорость набора** меняется в `main.py` → `TypingEngine`, параметр
  `setInterval` (мс на клавишу). По умолчанию 6 мс — быстро и видно.
- Если VC поменяет вёрстку и поле статьи не находится — селекторы собраны в
  одном месте (`JS_FOCUS_EDITOR` в `main.py`), их легко поправить.

## Локальный запуск (разработка)

```bash
pip install -r requirements.txt
python main.py
```

## Сборка .exe

Сборка настроена через GitHub Actions (`.github/workflows/build.yml`).
Запушьте репозиторий на GitHub — сборка запустится сама. Готовый архив
`VC-Doc-Importer-windows.zip` появится в **Actions → артефакты** (и в
**Releases** при создании тега `v*`). Внутри — папка с `VC-Doc-Importer.exe`,
запускайте его.
